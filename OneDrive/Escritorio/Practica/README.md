# Depósito de Elementos de Configuración - Baseline v1.0

## Objetivo
Implementar un repositorio ordenado para gestionar los Elementos de Configuración de Software (ECS) y establecer una línea base congelada y auditable.

## Estructura del Repositorio
- `/docs`: Documentación del sistema (SRS y SDD).
- `/src`: Código fuente de la implementación mínima.
- `/tests`: Pruebas unitarias/placeholders.
- `/config`: Plantillas de configuración.

## Ejecución
```bash
node src/index.js
