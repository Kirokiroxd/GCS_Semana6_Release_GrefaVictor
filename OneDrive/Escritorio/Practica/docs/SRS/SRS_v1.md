# Especificación de Requisitos de Software (SRS v1.0)

## Requisitos Funcionales (RF)
* **RF-001:** El sistema debe registrar nuevos usuarios con correo y contraseña.
* **RF-002:** El sistema debe autenticar usuarios previamente registrados.
* **RF-003:** El sistema debe permitir consultar la lista de productos disponibles.
* **RF-004:** El sistema debe permitir actualizar la información del perfil del usuario.

## Requisitos No Funcionales (RNF)
* **RNF-001 (Rendimiento):** El tiempo de respuesta del login debe ser menor a 2 segundos.
* **RNF-002 (Seguridad):** Las contraseñas deben almacenarse encriptadas mediante un algoritmo seguro.
